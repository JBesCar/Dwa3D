This repo contains the code used in the paper "DWA-3D: A Reactive Planner for Robust and Efficient Autonomous UAV Navigation in Confined Environments" (https://arxiv.org/abs/2409.05421).

There are two branches:

1) `jetson_orin`: The setup used in the real UAV for the experiments of the paper.
2) `simulation`: Offers a Docker to simulate an UAV with our exact architecture (including the PX4 autopilot) in Gazebo. It also offers the source code.
